MUREX Practice Help

This is an independent learning environment designed to practise Murex-style front-to-back workflows. Use the left navigation to explore modules. Start with Trade Capture, follow the lifecycle, then inspect Pricing, Risk, P&L, Confirmations and Settlement.

The data is simulated and the platform is not connected to a production Murex installation or live bank systems.
