Practice Architecture

This simulator is deliberately modelled around current MX.3 concepts: integrated front-to-back-to-risk workflows, operations/finance, enterprise risk, market data, configuration and APIs. It is an independent educational implementation with simulated data.

It imitates Murex-style concepts for learning; it does not reproduce proprietary MX.3 software.

SQL Practice Starter
SELECT t.trade_id, t.product_id, c.counterparty_name, p.position_amount, pnl.mtm
FROM trade t
JOIN product pr ON pr.product_id = t.product_id
JOIN counterparty c ON c.counterparty_id = t.counterparty_id
LEFT JOIN position p ON p.trade_id = t.trade_id
LEFT JOIN pnl ON pnl.trade_id = t.trade_id
WHERE t.trade_id = 'T20260911_001';

Exercise: identify the primary/foreign keys and explain what could cause PNL to use an older trade version.
